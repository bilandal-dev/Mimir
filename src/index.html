        Mailkonto
        
            
        Mimir spricht IMAP und SMTP. Bei Gmail unter Einstellungen, Konten, Sicherheit ein App-Passwort erzeugen – das Hauptpasswort gehört nicht hierher.
        

            
            
            
            
            
            
                
                
                
                
                
                
                
                
            
            
            
            
            
            
            
            
            
            
            
            
        Gespeichert wird das App-Passwort im Schlüsselbund des Systems, nicht in einer Datei von Mimir. Ohne Schlüsselbund – etwa auf einem Rechner ohne Anmeldung – bleibt die Anmeldung nur für diese Sitzung erhalten.
        
            
        Beide Server brauchen ein Zertifikat, das das System kennt. Mimir prüft es wie bei jeder anderen HTTPS-Verbindung; ein Mailserver mit einem selbstsignierten Zertifikat wird abgelehnt.
        
            
        
            
        
                
                
            
        
        
        
            

    
        
        
            
        Zertifikat der Instanz
        
            
        Die Instanz liefert ein selbstsigniertes Zertifikat. Mimir prüft die Zertifikatskette nicht, sondern merkt sich dieses eine Zertifikat und vergleicht es bei jedem Zugriff. Stimmt es nicht mehr, wird der Zugriff verweigert.
        
            
        Instanz: 
        
            
        Fingerabdruck (SHA-256)
        
            
        
            
        
            
        Zum Nachsehen auf dem Rechner:
                openssl s_client -connect HOST:443 < /dev/null 2>/dev/null | openssl x509 -noout -fingerprint -sha256
